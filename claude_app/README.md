# claude_app — Claude Desktop (Windows) 분석 모듈

담당 권찬결. 대상은 **Claude Desktop 앱**이다 (Electron, MSIX 설치 기준.
NSIS 설치본도 같은 경로 규칙으로 받는다).

도구는 둘이고 답하는 질문이 다르다.

| 도구 | 답하는 것 |
|---|---|
| **ChatTrace** | 무엇을 말했나 — 대화 원문 복원 |
| **ActTrace** | 누가 · 언제 · 무엇을 했나 — 행위 재구성 |

ActTrace 는 ChatTrace 를 **라이브러리로 import** 한다. 포크하지 않는다 —
포크하면 한쪽만 고치고 잊는다. E01/dd/vmdk 입력도 `chattrace.image` 를
그대로 쓴다.

## 폴더 구조

```
claude_app/
  tools/
    ActTrace.cmd        행위 재구성 진입점
    ChatTrace.cmd       대화 복원 진입점
    actrace/            ActTrace 패키지 (파서 8 · 규칙 39종)
    chattrace/          ChatTrace 패키지 — ActTrace 가 import 한다
      image/            E01 / dd / vmdk 직접 읽기 (마운트 안 한다)
    tests/              통제 테스트 10개
  demo_result/
    ActTrace/           실측 산출물 11종
    ChatTrace/          실측 산출물 8종
  산출물-설명.md
```

`actrace` 와 `chattrace` 는 **별개 패키지 둘**이다. 한 폴더에 같이 있는
이유는 ActTrace 가 ChatTrace 를 라이브러리로 쓰기 때문이고, 포크해서
두 벌로 두면 한쪽만 고치고 잊는다.

## 돌리는 법

```
tools\ChatTrace.cmd <이미지|수집물> <환경> <저장경로>
tools\ActTrace.cmd  <이미지|수집물> <환경> <저장경로>
```

위치 인자 셋은 **이미지 · 환경 · 저장 경로** 순서다 (2026-10-05 팀 합의).
기존 `-i` / `-o` / `--profile` 도 그대로 받는다.

```
ActTrace.cmd "D:\사건\CASE01.E01" claude-desktop/msix "C:\사건\CASE01-행위"
```

설치할 게 없다. **표준 라이브러리만** 쓴다 (Python 3.8+). E01 은 마운트하지
않고 직접 읽는다 — 마운트는 관리자 권한과 ACL 문제를 부른다.

`ActTrace --conversations <ChatTrace출력>` 을 주면 초안이 실제로 전송됐는지
대조하고, 메시지 UUIDv7 로 대화별 입력 구간을 역산한다.

## 산출물

통일 합의분 둘.

| 파일 | 내용 |
|---|---|
| `report.csv` | **4열 고정** — 행위 분류 \| 아티팩트 \| 경로 \| 아티팩트 등급 |
| `report.html` | 개요(환경) → 행위별 토글 → 같은 3열 표 → 상세 |

**아티팩트 등급은 느낌이 아니라 규칙이다.**

| 등급 | 정의 |
|---|---|
| **직접** | 그 아티팩트 **한 종류만으로** 확정(`confirmed`) 판정이 선 경우 |
| **보조** | 여러 아티팩트를 **함께** 봐야 하거나, 확정 아래 등급인 경우 |

한 아티팩트가 같은 행위에서 두 역할을 다 했으면 직접을 적는다. 이 4열은
**요약**이고, 어느 추론이 어느 관찰에서 나왔는지는 `behaviors.csv` 의
`supported_by` · `source_artifacts` 와 `observations.jsonl` 에 그대로 남는다.

나머지 산출물 전부는 [산출물-설명.md](산출물-설명.md) 에 파일마다 열 수 ·
줄 수 · 크기까지 실측값으로 적어 뒀다.

## 검증 상태

`demo_result/` 는 **실제 실험 수집물(T7)을 돌린 결과 그대로**다. 합성 표본이
아니다.

| | 수치 |
|---|---|
| 관찰 | 863건 (아티팩트 9종) |
| 추론 | 92건 · 규칙 **39종** |
| 판정 | 확정 62 · 유력 24 · 추정 2 · 판정불가 4 |
| 통일 4열 | 61줄 — 직접 48 · 보조 13 |
| 못 읽은 것 | 3건 (UserAssist 키 부재, `problems.csv` 에 신고) |

행위 Rule 은 **실측으로 맞춰 본 것**이다. 몇 가지만 들면,

- 삭제된 대화 3/3 을 확정, 안 지운 2개를 판정불가로. **오탐 0**
- Prefetch 실행횟수 오프셋 `0xC8` — 284/284 조건 만족, 233개 정확 일치
- 설치 4단계 `$MFT` 엔트리 순서가 선행 분석 수치 3개와 정확히 일치
- 타임존 역산 — 같은 로그아웃이 UTC(Local Storage)와 로컬(main.log) 양쪽에
  있어 차이 9시간 → UTC+9 자동 판정 (15분 격자, 오차 1.6초)
- `chat-draft-wipe-completed-at` 를 처음엔 B07(프롬프트 수정)에 붙였다가
  마커 로그와 대조해 틀린 걸 잡았다 — 로그아웃 +27초, 계정전환 +23초,
  프롬프트 수정과는 29분 차. **앱이 세션 정리하며 비운 것**이라 B03 으로
  옮겼다. 단독 증거로 못 쓰고 시간축 보조로만 쓴다

통제 테스트 10개(양성·음성·회귀)는 `tools/tests/test_payloads.py`
에 있다. 전부 통과한다.

한 번도 안 선 규칙 11종.

```
R-TEMPCHAT-01          R-TEMPCHAT-CLEARED-01   R-UPLOAD-LOCALPATH-01
R-ACCTDEL-01           R-DELETE-LEDGER-01      R-DRAFT-SENT-01
R-BROWSER-DOWNLOAD-01  R-FIRSTRUN-LOGLINE-01   R-MSIX-MANIFEST-01
```

**코드가 틀렸다는 뜻이 아니라 그 행위를 한 실험이 없다는 뜻이다.** 예를
들어 B12 는 Session Storage 의 `incognito_temporary_conversation_uuid`
키를 찾는데, 지금까지 수집한 어느 이미지에도 그 키가 없다 — 임시 대화를
쓴 적이 없어서다.

규칙 자체는 선행 분석(R1 업로드 · R3 임시 대화)에서 가져온 것이라 근거가
있지만, **내 손으로 재현해 맞춰 본 적은 없다.** 쓸 때 이 구분을 알고
써야 한다. B08 · B09 · B12 를 확정하려면 그 행위를 하는 수집을 따로
떠야 한다.

## 알아야 할 것 — 앱 버전이 복원 범위를 가른다

**2.9939.x 부터 대화 본문이 로컬에 저장되지 않는다.** 도구 결함이 아니다.

| | 2.2553.1 | 2.9939.2 |
|---|---|---|
| `react-query-cache` | 17건 · 외부 블롭 931,101 B | **1건 · 44 B · `.blob` 폴더 없음** |
| 답변 본문 | 복원된다 (22,784자) | **0자** |
| 질문 본문 | 복원된다 | 초안 조각으로 **83.6%** (225/269자) |
| 대화 목록 | 11개, 제목·상태 전부 | **0개** |

**요금제가 아니라 버전이다.** 같은 2.9939.2 에서 무료 계정으로 다시 돌려
동일 결과를 얻어 변수를 갈랐다.

60 GB E01 을 섹터 단위로 **전수 탐색**해 확정했다 — 비할당 영역 ·
`pagefile.sys` 포함, 답변에만 나올 고유명사 19종을 UTF-8 · UTF-16LE 두 벌로.
걸린 것은 전부 오탐이었다. 지워서 못 찾는 게 아니라 **처음부터 안 적는다.**

본문이 없어도 **받았다는 사실과 시각**은 남는다. Local Storage 이벤트 큐의
`claudeai.message.sent` → `perceived_ttft` → `first_text` → `perceived_ttlt`
를 엮어 "첫 글자까지 1.7초 · 전체 79.7초" 같은 판정을 세운다 (`R-REPLY-*`).

## 원본 저장소

도구 정본과 커밋 이력은 `ChankyulKwon/USB-Kit` (비공개) 에 있다. 여기에는
그 사본을 둔다. 수집 도구(FTK Imager · KAPE)는 **재배포 불가**라 빠져 있다.

NEWCONV-3471 What is a Python list?

[assistant] 2026-09-19T06:40:07.554734Z
A Python list is a built-in data structure that holds an ordered, mutable collection of items. You can think of it as a container that can hold multiple values in a single variable.

Key characteristics:

- **Ordered** — items keep the position you put them in.
- **Mutable** — you can change, add, or remove items after creating the list.
- **Heterogeneous** — items don't need to be the same type; you can mix strings, numbers, other lists, etc.
- **Indexed** — items are accessed by position, starting at `0`.

Example:

```python
fruits = ["apple", "banana", "cherry"]

print(fruits[0])       # "apple"
fruits.append("date")  # adds "date" to the end
fruits[1] = "blueberry" # replaces "banana"
print(fruits)          # ["apple", "blueberry", "cherry", "date"]
print(len(fruits))     # 4
```

Lists are created with square brackets `[]`, and support operations like slicing (`fruits[1:3]`), sorting (`fruits.sort()`), and searching (`"apple" in fruits`). They're one of Python's most commonly used data types, alongside tuples (immutable lists), dictionaries (key-value pairs), and sets (unordered unique items).

EXIST-7264 And what is a Python tuple?

[assistant] 2026-09-19T06:45:57.726354Z
A Python tuple is a lot like a list — an ordered collection of items — but with one key difference: **tuples are immutable**, meaning once created, you can't change, add, or remove items.

Key characteristics:

- **Ordered** — items keep their position.
- **Immutable** — can't be modified after creation.
- **Heterogeneous** — can mix types just like a list.
- **Indexed** — accessed by position, starting at `0`.

Example:

```python
coordinates = (10, 20)

print(coordinates[0])   # 10
print(len(coordinates)) # 2

# This would raise an error:
# coordinates[0] = 99   # TypeError: 'tuple' object does not support item assignment
```

Tuples are created with parentheses `()` (though the parentheses are technically optional in many contexts — the comma is what actually matters):

```python
point = 1, 2, 3   # still a tuple
single = (5,)     # need a trailing comma for a one-item tuple
```

**Why use a tuple instead of a list?**

- **Safety** — immutability prevents accidental changes to data that shouldn't change.
- **Performance** — tuples are slightly faster and more memory-efficient than lists.
- **Hashability** — because they're immutable, tuples can be used as dictionary keys or set elements (as long as their contents are also hashable), while lists cannot.

A common use case is returning multiple values from a function:

```python
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([4, 1, 7, 3])
```

EDITED-1930 And what is a Python set?

[assistant] 2026-09-19T06:50:20.986876Z
A Python **set** is a built-in data structure that holds an **unordered collection of unique items**. It's useful when you need to store items without duplicates and don't care about their order.

Key characteristics:

- **Unordered** — items have no fixed position or index, so you can't access them by index.
- **Unique** — duplicate values are automatically removed.
- **Mutable** — you can add or remove items after creation (though the items themselves must be immutable, like numbers, strings, or tuples).
- **Fast membership testing** — checking if something is `in` a set is very efficient.

Example:

```python
fruits = {"apple", "banana", "cherry"}

fruits.add("date")        # adds "date"
fruits.add("apple")       # no effect, "apple" is already there
fruits.remove("banana")   # removes "banana"

print(fruits)             # order not guaranteed, e.g. {"apple", "cherry", "date"}
print("cherry" in fruits) # True
print(len(fruits))        # 3
```

You create a set with curly braces `{}` or the `set()` function. Note: `{}` alone creates an empty **dictionary**, not a set — for an empty set, use `set()`.

Sets also support classic math operations:

```python
a = {1, 2, 3}
b = {2, 3, 4}

print(a | b)  # union: {1, 2, 3, 4}
print(a & b)  # intersection: {2, 3}
print(a - b)  # difference: {1}
print(a ^ b)  # symmetric difference: {1, 4}
```

Sets are great for deduplicating lists, checking membership quickly, and comparing collections of items.
